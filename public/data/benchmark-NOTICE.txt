Artificials benchmark snapshots

LiveBench: published per-task scores, from the LiveBench team.
Source: https://livebench.ai/ and https://github.com/LiveBench/new-livebench
The LiveBench datasheet specifies Apache License 2.0 for its benchmark suite:
https://github.com/LiveBench/LiveBench/blob/main/docs/DATASHEET.md#dataset-distribution
License copy: /data/livebench-APACHE-LICENSE.txt
Artificials modifications: equal-weight task/category aggregation for complete
results only, rounding to two decimals, competition ranking, JSON normalization,
provider-family labels. Model configurations and source scores are preserved.
The source's evaluation release date and its revision/check timestamps are distinct.

Epoch AI: benchmark evaluations run by Epoch AI, and the Epoch Capabilities Index.
Epoch AI, 'Capabilities & Benchmarking'. Published online at epoch.ai.
Retrieved from https://epoch.ai/benchmarks (data: https://epoch.ai/data/benchmark_data.zip).
Licence: Creative Commons Attribution 4.0 International,
https://creativecommons.org/licenses/by/4.0/
Epoch AI's own evaluations are used as model tests. From the results in the
archive that Epoch AI compiles from other projects, four are republished, each
credited to its creators below: the Terminal-Bench 2.0 leaderboard (Apache-2.0),
and DeepSWE, CursorBench and METR's time horizons, whose publishers state no
licence of their own and which Epoch AI republishes under CC BY 4.0. Artificials
is a free, non-commercial site.
Artificials modifications: fractions converted to percentages, the latest run
kept when a configuration was tested more than once, standard errors converted
to percentage points, rounding to two decimals, competition ranking, JSON
normalization, provider-family labels, and matching of results to model
profiles. Plain-language test descriptions are written by Artificials.

Epoch AI model records: model_metadata.csv from the same archive, under the same
licence. Used fields: model name, the model identifiers Epoch AI evaluated, release
date, organization, country, access category and estimated training compute.
Artificials modifications: identifiers grouped by model name, text trimmed,
implausible compute values dropped, compute rounded to three significant figures,
and records matched to model profiles by exact identifier. Release dates and access
categories on capability-index rows come from eci_scores.csv. Training compute is
Epoch AI's estimate and is labelled as such wherever it is shown.

Terminal-Bench 2.0: leaderboard results for coding agents, by the Terminal-Bench
project and the teams that submitted each agent.
Source: https://www.tbench.ai/leaderboard/terminal-bench/2.0
Leaderboard data: https://huggingface.co/datasets/harborframework/terminal-bench-2-leaderboard
Licence: Apache License 2.0, https://www.apache.org/licenses/LICENSE-2.0
License copy: /data/livebench-APACHE-LICENSE.txt (the same Apache License 2.0 text)
The scores are read from Epoch AI's compilation of the leaderboard
(terminalbench_external.csv in the Epoch AI archive above, CC BY 4.0). They are
published only while the leaderboard dataset states Apache-2.0.
Artificials modifications: fractions converted to percentages, standard errors
converted to percentage points, rows without a leaderboard source dropped, agent
names trimmed and merged across spellings, an entry listed more than once kept
once (latest run), competition ranking, matching of models to profiles, and a
label for agents built by the model's maker. Artificials does not run these tests.

DeepSWE: by Datacurve. Source: https://deepswe.datacurve.ai/
Scores (pass@1), average API cost, output tokens and agent steps per task, with
every model in mini-swe-agent, read from Epoch AI's compilation
(deepswe_external.csv, CC BY 4.0).
Artificials modifications: fractions converted to percentages, standard errors
derived from the published 95% intervals, rounding, ranking and matching of
models to profiles.

CursorBench: by Cursor (Anysphere). Source: https://cursor.com/cursorbench
Scores, average cost, tokens and steps per task, read from Epoch AI's
compilation (cursorbench_external.csv, CC BY 4.0).
Artificials modifications: fractions converted to percentages, rounding,
ranking and matching of models to profiles.

METR time horizons: by METR. Source: https://metr.org/
The length of task, in the time skilled people need, that a model completes
half the time, with its interval and the length completed 80% of the time, read
from Epoch AI's compilation (metr_time_horizons_external.csv, CC BY 4.0).
Artificials modifications: only the latest method version kept, an entry listed
twice merged, rounding, ranking and matching of models to profiles.

SWE-bench: by the SWE-bench team (Princeton and Stanford researchers and
contributors). Source: https://www.swebench.com/ and
https://github.com/SWE-bench/swe-bench.github.io (data/leaderboards.json).
Licence: Creative Commons Attribution-NonCommercial 4.0 International,
https://creativecommons.org/licenses/by-nc/4.0/
Used only on this free, non-commercial site; published only while the source's
LICENSE file carries that licence.
Artificials modifications: from the SWE-bench Verified leaderboard, the
bash-only (mini-SWE-agent) runs as a model test with average cost and model
calls per issue, and other agents' single-attempt, single-model entries as agent
results; Claude model names reordered to the maker's naming, the latest run of
each configuration kept, ranking and matching of models to profiles.

T2I-CoReBench: Ouxiang Li, Yuan Wang, Xinting Hu, Huijuan Huang, Rui Chen,
Jiarong Ou, Xin Tao, Pengfei Wan, Xiaojuan Qi, and Fuli Feng.
Source: https://t2i-corebench.github.io/
Paper: https://arxiv.org/abs/2509.03516
The source website is licensed under CC BY-SA 4.0:
https://creativecommons.org/licenses/by-sa/4.0/
The image benchmark portion of benchmarks.json is adapted under that same license.
Artificials modifications: extracted primary Gemini 2.5 Flash evaluator rows,
excluded prompt-rewriting variants, sorted published overall scores, normalized
as JSON with provider-family labels. No website design or code is copied.

Scores measure performance only within their stated benchmark, not universal
model quality. Artificials does not conduct these evaluations. Model releases,
benchmark edition, source modification time, and retrieval time are not equivalent.
An unreported result is absent, never assigned zero. All retained scores are public
published results, not generated or demo scores.
