# Artificials

Build clean, secure, lightweight software with a professional UI responsive across mobile and desktop. Product copy is English; communicate with the owner in Indonesian.

- Use SVG icons, not emoji. Base the interface on black, silver and white with thoughtful scroll animation, keyboard accessibility and reduced-motion support. For charts and model analysis, color is welcome: use the validated skill-area palette in `src/domain-colors.css` for skill areas, each maker's brand color from `shared/makers.ts` for model makers (always beside the maker's logo or name), and keep text in neutral colors. Logos and icons keep their original colors, except the footer's social icons, which are white.
- Never invent AI model rankings, benchmark scores or freshness. Credit every source and its licence; distinguish catalog metadata from measured benchmarks. The owner asked for no update, check or retrieval times anywhere on the site (25 September 2026): keep those times in the data files only. The rankings page may still say when a refresh is delayed.
- Keep admin.md local only. Never add it to Git, deploy uploads, public assets or build output. Never commit secrets.
- After completed coding changes, run appropriate checks, review the diff, then commit and push to the Artificials GitHub repository. Do not push incomplete work or secrets.
- The owner selected Cloudflare Free. Do not purchase services or upgrade plans.
- Artificials is free and non-commercial (owner decision, 25 September 2026). Say it is non-commercial; do not describe it as run by volunteers. Do not add paid plans, checkout, ads, sponsored listings or paid AI features. Data under non-commercial licences such as CC BY-NC may be used; credit every source and keep its licence terms.
