# Systems collection: artwork provenance

Created with the built-in image_gen tool on 27 September 2026. Each of the 20 new articles has a separately generated conceptual illustration; none is a photograph of a real event, a product screenshot, or a measured chart. No external image was copied. Original outputs remain in the local generation archive.

Published assets are `public/editorial/insight-<key>.webp` at 1200 x 800 and matching `-small.webp` variants at 640 x 427, encoded with cwebp at quality 84. The existing ArticleCover dimensions, responsive selection, lazy loading, and page layout are retained. `shared/editorial-covers.ts` maps each article slug to its asset and descriptive alt text; metadata uses the same mapping. Existing articles retain their previous covers.
